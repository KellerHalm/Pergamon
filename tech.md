# Техническое задание (ТЗ) на разработку приложения «Pergamon»

## 1. Описание проекта
**Суть:** Локальное многофункциональное приложение для учета, каталогизации и взаимодействия с медиаконтентом (книги, манга, фильмы, сериалы, аниме) с возможностью облачной синхронизации.
**Ключевая особенность:** Хранение данных на устройстве пользователя с синхронизацией через личные облака (Яндекс Диск, Google Drive), наличие визуальной "Виртуальной полки" и встроенного ИИ для взаимодействия с загруженным контентом.

## 2. Архитектура и стек технологий (рекомендация)
*   **Тип приложения:** Кроссплатформенное (Desktop + Mobile).
*   **Рекомендуемый стек:** Tauri + SvelteKit.
*   **База данных:** SQLite.
*   **Синхронизация:** Протокол WebDAV (идеально для Яндекс Диска, Nextcloud) и API популярных облаков.

## 3. Базовая структура сущности "Тайтл"
Каждый добавляемый элемент должен содержать следующие поля:
*   **Тип:** Читать / Смотреть.
*   **Категория:** Книга, Манга, Комикс, Ранобэ / Фильм, Сериал, Аниме, Мультфильм (с возможностью добавления кастомных).
*   **Названия:** Массив названий (Оригинал, Английское, Русское, Альтернативные).
*   **Обложка/Постер:** Изображение (загрузка с устройства или по ссылке).
*   **Описание (Синопсис):** Текстовое поле.
*   **Авторы/Создатели:** Режиссер, Автор, Художник, Студия.
*   **Жанры/Теги:** Множественный выбор (с возможностью создавать свои).
*   **Оценка:** 0.0 – 5.0 (можно сделать шаг 0.5 или 10-балльную систему под капотом).
*   **Статус (Список):** Прочитано/Просмотрено, В процессе, Отложено, Брошено, Запланировано + *Кастомные списки/закладки*.
*   **Прогресс (Важное дополнение!):** Томы, Главы, Страницы / Сезоны, Серии, Минуты.
*   **Заметки:** Rich-text редактор для личных мыслей, рецензий, цитат.
*   **Прикрепленные файлы (V2):** Ссылки на локальные файлы (EPUB, PDF, MP4, MKV).

## 4. Функциональные требования (MVP – Первая версия)

### 4.1. Главный экран (Каталог)
*   Отображение тайтлов в виде карточек (сетка) или списка.
*   **Сортировка:** По дате добавления, по алфавиту, по оценке, по дате обновления.
*   **Фильтрация:** По типу, категории, статусу, тегам.
*   **Глобальный поиск:** Поиск по всем названиям и авторам.

### 4.2. Страница тайтла
*   Отображение всей информации из п.3.
*   Удобные кнопки "+" и "-" для быстрого изменения прогресса (например, +1 просмотренная серия).
*   Раздел с личными заметками и рецензией пользователя.

### 4.3. Виртуальная библиотека (Имитация комнаты)
*   Отдельный экран с визуализацией полок.
*   **Для читаемого:** Отображаются корешки книг/манги (генерация корешка на основе цвета обложки и названия, если нет оригинального).
*   **Для смотримого:** Отображаются VHS-кассеты, DVD-боксы или бобины с пленкой.
*   Возможность создавать "Полки" и вручную или автоматически расставлять на них тайтлы.

### 4.4. Добавление тайтла (Модуль ввода)
*   **Ручной ввод:** Заполнение полей пользователем вручную.
*   Валидация полей (название обязательно, остальное опционально).

### 4.5. Синхронизация и Бэкап
*   Авторизация в Яндекс Диск (через WebDAV или OAuth).
*   Кнопка "Синхронизировать сейчас" и настройка "Авто-синхронизация при запуске/закрытии".
*   Экспорт/Импорт базы данных в формате JSON или резервного файла `.sqlite` (на случай перехода на другое устройство офлайн).

## 5. План развития (Roadmap) – Будущие обновления

### Фаза 2: Автоматизация добавления
*   **Парсинг по ссылке:** Пользователь вставляет URL (MangaLib, Shikimori, Kinopoisk, IMDb, Goodreads), приложение скачивает метаданные (названия, обложку, описание) и предзаполняет форму.
*   **Интеграция с API (Global Search):** В окне добавления появляется вкладка "Поиск в сети". Приложение ищет тайтл через открытые API (TMDB, Shikimori, Google Books API) и добавляет его в локальную базу в один клик.

### Фаза 3: Локальный медиаплеер и читалка
*   Возможность привязать к карточке тайтла локальный файл (например, скачанный фильм или книгу EPUB).
*   Открытие книги/видео прямо внутри приложения.
*   Автоматический учет прогресса при чтении/просмотре внутри приложения.

### Фаза 4: Интеграция Искусственного Интеллекта (ИИ)
*   **BYOK (Bring Your Own Key):** Настройки для ввода API-ключей от OpenAI (ChatGPT), Anthropic (Claude) или подключение локальных моделей (Ollama), чтобы не платить за сервера.
*   **AI-Собеседник:** Чат на странице тайтла. Промпт под капотом: *"Ты эксперт по [Название тайтла]. Пользователь оценил его на [Оценка]. Поддержи разговор об этом произведении."*
*   **RAG (Retrieval-Augmented Generation) на основе контента:** Если к тайтлу прикреплен текст книги (.txt, .epub, .pdf) или субтитры к фильму, ИИ индексирует этот файл (создает векторную базу локально). Пользователь может:
    *   Спросить: *"В какой главе произошла битва X?"*
    *   Спросить: *"Напомни, как зовут брата главного героя?"*
    *   Попросить: *"Задай мне 5 вопросов на знание сюжета этой книги, хочу проверить себя."*

### Фаза 5: Статистика пользователя
*   Графики: сколько книг прочитано/сериалов посмотрено в этом году.
*   Любимые жанры (круговая диаграмма).
*   Общее время (страниц прочитано, часов просмотрено).

## 6. Дизайн и UX (Пользовательский опыт)
*   **Темизация:** Поддержка светлой и темной темы. Возможность выбора "акцентного цвета" приложения.
*   **Адаптивность:** Приложение должно красиво смотреться как на узком экране смартфона, так и на широком экране монитора (где карточки тайтлов выстраиваются в много колонок).
*   **Скевоморфизм (для полок):** Использование текстур дерева, пластика (для кассет) и бумаги для создания уютной атмосферы в разделе "Виртуальная библиотека", в то время как Главный экран остается минималистичным и современным.
