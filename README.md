# Pergamon

Локальное десктоп-приложение для учёта и каталогизации медиаконтента: книги, манга, комиксы, ранобэ, фильмы, сериалы, аниме, мультфильмы. Все данные хранятся на устройстве пользователя (SQLite), с опциональной синхронизацией через личное облако по WebDAV (Яндекс Диск, Nextcloud и др.).

## Возможности

- **Каталог** — карточки тайтлов в виде сетки, сортировка (по дате добавления, алфавиту, оценке, дате обновления), фильтры по типу/категории/статусу/тегам, глобальный поиск по названиям и авторам.
- **Страница тайтла** — названия (оригинал, английское, русское, альтернативные), обложка, описание, авторы/студия, жанры и теги, оценка, статус (прочитано, в процессе, отложено, брошено, запланировано), прогресс (тома, главы, страницы / сезоны, серии, минуты) с быстрыми кнопками «+»/«−».
- **Заметки** — встроенный rich-text редактор (TipTap) для рецензий, мыслей и цитат по каждому тайтлу.
- **Виртуальные полки** — экран с визуализацией библиотеки: корешки книг окрашиваются в доминирующий цвет обложки.
- **Справочники** — персонажи, люди (авторы, режиссёры, художники) и студии с привязкой к тайтлам.
- **Синхронизация и бэкап**:
  - WebDAV-синхронизация базы с личным облаком (по умолчанию каталог `/Pergamon` на `https://webdav.yandex.ru`);
  - авто-синхронизация при запуске и закрытии приложения (настраивается);
  - экспорт/импорт базы в JSON (со слиянием и дедупликацией) и в файл SQLite.

## Стек технологий

| Слой | Технологии |
|---|---|
| Backend | Go 1.25, [Wails v2](https://wails.io) |
| База данных | SQLite (драйвер `modernc.org/sqlite`, без CGO) |
| Синхронизация | WebDAV (`gowebdav`) |
| Frontend | SvelteKit 2, Svelte 5, TypeScript, Vite 5 |
| Редактор заметок | TipTap 3 |
| Иконки | lucide-svelte |

## Требования

- **Go** ≥ 1.25 — [go.dev/dl](https://go.dev/dl/)
- **Node.js** ≥ 18 с npm — [nodejs.org](https://nodejs.org/)
- **Wails CLI v2**:
  ```bash
  go install github.com/wailsapp/wails/v2/cmd/wails@latest
  ```
- На Windows: WebView2 Runtime (предустановлен в Windows 10/11).

Проверить готовность окружения:

```bash
wails doctor
```

## Запуск в режиме разработки

Из корня репозитория:

```bash
wails dev
```

Команда собирает Go-часть, поднимает Vite dev-сервер для фронтенда и открывает окно приложения. Изменения в Go-коде и Svelte-компонентах подхватываются «на лету».

Разработка только фронтенда (без Go-бэкенда, методы API работать не будут):

```bash
cd frontend
npm install
npm run dev
```

Проверка типов фронтенда:

```bash
cd frontend
npm run check
```

## Сборка

Production-сборка (фронтенд собирается автоматически):

```bash
wails build
```

Готовый исполняемый файл появится в `build/bin/Pergamon.exe`.

Полезные флаги:

```bash
wails build -debug    # сборка с devtools
wails build -platform windows/amd64   # явное указание платформы
```

## Тесты

```bash
go test ./...
```

Тесты покрывают работу с путями данных (`paths_test.go`) и логику импорта/экспорта JSON (`internal/sync/json_test.go`).

## Где хранятся данные

| Что | Путь (Windows) |
|---|---|
| База данных | `%APPDATA%\Pergamon\pergamon.db` |
| Обложки | `%APPDATA%\Pergamon\covers\` |
| Экспорт JSON | `%APPDATA%\Pergamon\pergamon-export-<дата>.json` |

При первом запуске приложение автоматически переносит базу и обложки из папки старого приложения **Mediateka** (`%APPDATA%\Mediateka`), если данных в новой папке ещё нет.

## Структура проекта

```
Pergamon/
├── main.go              # точка входа Wails, настройки окна
├── app.go               # Go-методы, проброшенные во фронтенд (Bind)
├── paths.go             # каталог данных пользователя, миграция с Mediateka
├── internal/
│   ├── store/           # SQLite-хранилище: тайтлы, заметки, полки, персонажи, студии, люди
│   ├── sync/            # WebDAV-синхронизация, экспорт/импорт JSON и SQLite
│   └── cover/           # сохранение обложек, вычисление доминирующего цвета
├── cmd/                 # вспомогательные CLI-утилиты для тестов БД
├── frontend/            # SvelteKit-фронтенд
│   └── src/routes/      # страницы: каталог, add, title, shelf, characters, people, studios, settings
└── build/               # иконки, манифест, выходная сборка (build/bin)
```
